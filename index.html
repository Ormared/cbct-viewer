left-click = move crosshair · scroll = next slice · middle- or shift-drag = pan · double-click = reset contrast
contrast (drag): up/down = darker/brighter, right/left = softer/sharper; works in 3D too
contrast (box): fits the window to the values inside the box
measure angle: right-drag one arm, then right-click to place the other
pan: right-drag moves the image, scroll zooms the 2D slices
3D: drag rotates · scroll zooms, or moves the cut while clipping · double-click jumps the crosshair there
keys (click the image first): V layout · C clip presets
Values are raw CBCT densities (intercept-corrected), not true HU.
